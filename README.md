# minecraft-autoclicker

An autoclicker for automating routine tasks in Minecraft. 

This is a lightweight tool you can use in your singleplayer world or local server to grind materials using a cobblestone generator or a mob farm.

---

## 🚀 Features & Modes

* **Pickaxe Mode:** Automatically holds down the left mouse button for continuous mining.
* **Sword Mode:** Clicks the left mouse button once at a specified time interval (loaded directly from the configuration file).
* **Off:** A safety function that instantly deactivates all active modes and releases the mouse button.

You can easily customize all hotkeys and the click interval inside the `config.toml` file.
